# TECHZONE: E-Commerce Inventory System

## Project Overview

TechZone is a C++ console-based E-Commerce Inventory System developed as a final project. It simulates an online shopping platform where customers can browse products, manage their shopping cart, and place orders. It also provides administrative functions for managing product inventory.

## System Features

### Customer Features
- Browse the product catalog.
- Search and sort products.
- Add products to the shopping cart.
- Manage wishlist.
- Place orders.
- View order information.

### Admin Features
- Manage product inventory.
- Add, edit, and delete products.
- Monitor product stock.
- Manage product information.

## Data Structures and Algorithms

The project demonstrates the use of:

- **Dynamic Array** – Stores and manages product records.
- **Binary Search Tree (BST)** – Organizes products using their IDs.
- **Doubly Linked List** – Manages shopping cart items.
- **Singly Linked List** – Manages wishlist items.
- **Circular Linked List** – Manages promotional banners.
- **Stack** – Supports undo and redo operations.
- **Queue** – Manages customer orders.
- **Sorting and Searching Algorithms** – Helps locate and organize products.
